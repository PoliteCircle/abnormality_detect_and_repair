## 4. 用命令复核三类代表性结果

在仓库根目录运行：

```powershell
cd "D:\学习\abnormality_detect_and_repair"

.\.venv\Scripts\python.exe main.py `
  --case qingdao_port_simple `
  --log-file global_log_1.txt

.\.venv\Scripts\python.exe main.py `
  --case qingdao_port_simple `
  --log-file global_log_5.txt

.\.venv\Scripts\python.exe main.py `
  --case quote_order `
  --log-file global_log_2.txt
```

应分别看到：

1. `global_log_1.txt`：货代和船代的 MinAS 为 `.(M2,M3)`；规则5 `.(M2,M3) -> |(M2,M3)` 通过正常迹 7/7、异常迹 1/1。
2. `global_log_5.txt`：港口的 MinAS 为 `M7`；规则2 `M7 -> +(M7,tau)` 通过正常迹 7/7、异常迹 1/1。
3. `quote_order/global_log_2.txt`：排他选择的两个分支同时出现，程序生成规则8“排他选择改为并行”；其中一个参与方可以通过严格复验，另一个参与方因正常行为保留检查失败而不会被误报为有效修复。

每次运行后查看：

```powershell
Get-Content `
  output\qingdao_port_simple\global_log_1\analysis-report.json `
  -Encoding utf8
```

论文中的运行截图建议至少包含输入文件绝对路径和 SHA-256、异常投影、MinAS、候选规则以及正常/异常消息迹复验结果。不要只截最终“有效/无效”一行。

## 5. 保留新的统计口径

不要把新表改回旧的“全部成功”结果。本次使用当前代码实际逐一重跑了8个案例、67个日志，结果是：

- 程序执行成功：67/67；
- 至少锁定一个潜在异常子流程：65/67；
- 严格有效修复：44/67个日志输入；
- 修复作用域：94/118个存在严格有效候选；
- 分析流水线耗时：平均4.0449秒，标准差0.1841秒，范围3.9010--5.2563秒。该计时不包含Python模块导入、JSON序列化写入和终端打印。

“严格有效”要求候选同时满足定义7.17、通过全部正常消息迹、通过全部异常消息迹。不要只用“能通过异常消息迹”判成功。
